10. FINGERPRINTING & OSINT METHODOLOGY

How You Were Identified & Why OSINT Is Legal

01 // Passive Browser Fingerprinting

Modern browsers reveal an astonishing depth of hardware, graphics, and system parameters without asking for permissions or setting persistent cookies. WebGL renderer strings, canvas text metrics, CPU core counts, WebRTC local candidate structures, and precise pointer scroll deltas can be combined into a uniquely identifiable device signature.

Because every device possesses slight hardware and font configuration variances, these zero-permission browser APIs allow trackers and security systems to re-identify your machine across different web domains in real time.

02 // Open Source Intelligence (OSINT)

OSINT refers to the practice of collecting and correlating information from publicly available sources. The lookup tool above operates strictly within public boundaries — querying publicly indexed user handles, domain records, platform profiles, and public API endpoints.

No credential theft, private account bypass, or unauthorized access is performed. Every candidate, link, and evidence score surfaced by Deus originates from open data that was already accessible on the public web.

03 // Responsible Use & Privacy Hygiene

Understanding how passive fingerprinting and identity correlation work is the first step toward digital self-defense and threat modeling. By exposing these signals transparently, Deus allows researchers and individuals to audit their online exposure and understand how data points connect across platforms.

Responsible Use Notice: This toolkit is designed for self-auditing, research, and legitimate open-source intelligence verification. Users are responsible for adhering to applicable privacy laws and platform terms of service.
